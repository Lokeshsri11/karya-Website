Coding agents tend to pick one of two defaults: ask before every command, or run everything on your host. Both fail, in opposite directions.

## The three modes

| mode | read · list · search | write · edit | bash |
| --- | --- | --- | --- |
| plan | run | refused | run · read-only sandbox |
| default | run | ask, with diff | run · sandboxed |
| accept-edits | run | run | run · sandboxed |

## A denial is information

Deny with a reason and the call does not run. The reason goes back to the model as a structured result, so it can propose something else or stop.
